# Lab 5: Design with Sound & Vision

## Concept

“A Sunny Afternoon in Toronto” is a 75-second interactive soundscape. It follows a short walk from city streets, through a park path, and to the waterfront.

## Technical features

- HTML5 audio with a custom play/pause button
- Timeline and volume controls
- JavaScript time-based scene changes
- Web Audio API sound-level animation
- Animated streetcar, birds, sunlight, and city image
- Responsive layout for desktop and mobile

## Files

- `index.html` — page structure
- `style.css` — layout, colours, and animation
- `script.js` — audio controls and interaction
- `audio/sunny-toronto-soundscape.wav` — original 75-second soundscape
- `images/toronto-waterfront.svg` — original vector illustration

No external media assets are used.
